ResulTV-VDM
                                                          Datasheet


A Cost-Effective Alternative
                                                             ResulTV-VDM is a simplified version of ResulTV. Like the
                                                             VDM option for Vision-series cameras, the content of the
                                                             ResulTV-VDM layout is controlled by the data received.



The source applications (FinishLynx, FieldLynx, FieldLynx Lite or LynxPad) come standard with pre-defined and
customizable ResulTV-Video scoreboards scripts to create modern and eye-catching layouts for all types of events.




                                                               .
Simple Product for Complex Applications
•     Easy configuration – ready to receive data at start-up
•     Automatically scales to your pre-set display size
•     Instant layout design from source data
•     Displays running time, start lists, results, standings or
      photo-finish images
•     Supports data stream from FinishLynx,               FieldLynx,
      FieldLynx Lite, LynxPad and ReacTime.
•     Horizontal scrolling feature
•     Built-in ability to communicate using TCP/IP or UDP
      network protocols
•     Capability to use the full range of Windows Fonts, including character-based languages such as Korean,
      Japanese, Chinese, etc.
•     Resolution limited to the size of the display purchased with the solution
•     Requires Windows PC with USB and network ports.
•     Compatible with the Lynx Portable Display, 1/2/3-sided Infield Display and Lynx 360 Display
