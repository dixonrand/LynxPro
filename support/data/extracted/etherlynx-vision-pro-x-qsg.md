Introduction
In this QSG, you will learn how to configure the FinishLynx network, set up the EtherLynx Vision PRO X camera and align
it with the finish line using the EasyAlign software feature.
For more detailed or advanced instructions, consult the online FinishLynx Operator’s Manual (help.finishlynx.com) or the
technical support section of our website: www.finishlynx.com/support/.

PRO TIP          Best Practice
1. Zoom in as much as possible to fill the field of view. Avoid dead space at the top or bottom.
2. Use LuxBoost to keep the Gain value as low as possible to reduce the image noise.
3. Adjust the Frame Rate to match the speed of the object.
